eReaderPlus

An ebook reader that shows books with an up-to-date browser engine. Opens EPUB, PDF, MOBI, AZW3, FB2, CBZ, DjVu, CHM and LIT.

Windows This device

Windows 10 or 11

Download for Windows

  1. Open the downloaded eReaderPlus-Setup.exe.
  2. If Windows says “Windows protected your PC”, click More info, then Run anyway.
  3. eReaderPlus installs in a few seconds and starts. Open it later from the Start menu or the desktop icon.

New versions install themselves automatically.

Android This device

Android 7.0 or newer

Download for Android

  1. Open the downloaded eReaderPlus.apk (from the notification or your Downloads).
  2. If asked, allow your browser to install unknown apps, then go back.
  3. Tap Install. If Play Protect warns about an unknown app, tap More details, then Install anyway.
  4. Start eReaderPlus from its icon on the home screen or in the app list.

To update, download and install again from this page. Your books and settings are kept.
